# Эмулятор командной строки ОС (Вариант 15)

## 1. Общее описание
Программа эмулирует работу командной строки UNIX-подобной ОС. 
Поддерживает виртуальную файловую систему (VFS) в памяти, 
выполнение стартовых скриптов и интерактивный режим REPL.

## 2. Описание функций и настроек
### Параметры командной строки:
- `--vfs-path` — путь к физической директории, которая загружается в память как VFS.
- `--script` — путь к стартовому скрипту с командами (останавливается при первой ошибке).

### Реализованные команды:
- `ls` — выводит содержимое текущей директории.
- `cd <dir>` — переходит в указанную директорию.
- `history` — выводит историю введенных команд.
- `cal` — выводит календарь на текущий месяц.
- `mv <src> <dst>` — перемещает/переименовывает файл или папку в памяти VFS.
- `exit` — выход из эмулятора.

### Особенности:
- Приглашение к вводу формируется из реальных данных ОС (`username@hostname:dir$`).
- Поддерживается раскрытие переменных окружения (например, `$HOME`).
- VFS загружается в память, реальные файлы на диске не модифицируются.

## 3. Сборка и запуск
```bash
# Запуск с VFS
python3 -m src.main --vfs-path ./my_vfs

# Запуск со скриптом
python3 -m src.main --vfs-path ./my_vfs --script scripts/startup.txt
