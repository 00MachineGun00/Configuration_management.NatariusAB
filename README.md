# Эмулятор оболочки UNIX-подобной ОС (Вариант 15)

## 1. Общее описание
Эмулятор командной оболочки. Реализованы этапы 1–3:
- REPL с приглашением `user@host:cwd$`
- парсер с кавычками и раскрытием `$VAR`
- команды-заглушки `ls`, `cd`, команда `exit`
- CLI-параметры `--vfs`, `--script`, `--debug`
- VFS в памяти из директории на диске

## 2. Функции и настройки
| Опция | Назначение |
|---|---|
| `--vfs PATH` | путь к VFS-директории |
| `--script PATH` | путь к стартовому скрипту эмулятора |
| `--debug` | вывод параметров при запуске |
